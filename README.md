# Rent A Car System

Ky është një projekt i thjeshtë i zhvilluar në Java si pjesë e kursit në ICK.

## Përshkrimi
Aplikacioni lejon përdoruesin të:
- zgjedh veturën nga lista
- vendos numrin e ditëve të qirasë
- kalkulon automatikisht çmimin total
- shikon informacion për stafin

## Teknologjitë e përdorura
- Java
- IntelliJ IDEA

## Qëllimi i projektit
Ky projekt është zhvilluar për të praktikuar bazat e programimit në Java, përfshirë:
- strukturën e klasave
- logjikën e programimit
- input/output nga përdoruesi
